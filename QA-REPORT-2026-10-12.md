# Simulated user testing - netflix.com, 2026-10-12

Five parallel test agents drove the extension on the live, signed-in netflix.com in the Claude desktop browser
(Chromium). The extension was injected as a page script with a `browser.storage` shim and a fake "standard"
gamepad; each agent had its own tab and area. The coordinator re-checked the top findings in a visible tab at
1280x800. Nothing in the repository was changed by the testers.

**Environment caveats.** Background tabs are "hidden" in Chromium: `requestAnimationFrame` runs at ~1-2 fps,
smooth scrolling and lazy row loading stop, and `onAction` returns early. The agents shimmed around this, but
timing-sensitive results from background tabs need confirming in Firefox with a real pad. Video playback is
blocked by DRM (M7701-1003) in this browser, so the player could only be entered and exited. Visiting
`/ProfilesGate` cleared the active profile in the agents' tabs (the main tab was unaffected).

## Confirmed findings (reproduced in a visible tab)

1. **Major - "More like this" cards in the title dialog can't be opened; A toggles My List instead.**
   Open any dialog, hold Down past the episodes. The ring lands on the 46x46 `add-to-my-list` button *inside*
   each `titleCard--container` card, never on the card. Down/Up step from one card's My List button to the next.
   Pressing A there adds an unrelated title to My List (this happened during testing; it was undone).
   Cause: `dedupeNested` (content.js ~309) keeps the inner element when it is under 80% of the parent's area,
   so the 237x355 card is dropped. Note: clicking a More-like-this card on the current UI starts playback
   rather than opening its dialog, so `startsPlayback` matching `titleCard--container` is right.

2. **Minor - Start (Done) on the on-screen keyboard leaves the ring on the search input, not a result.**
   After typing, Start closes the OSK and `closeOsk()` (~1202) calls `setFocus(osk.input)`. Reaching the first
   result card takes four Downs (through Netflix's suggestion links). Expected: land on the first result.

3. **Minor - Profile gate not recognised.** The gate (served at `/browse`) uses
   `button[data-uia="profile-selector+tile-<id>"]`, `profile-selector+add`, `profile-gate-screen+manage`.
   `confirmLabel` (~95) and `pickInitial` (~409) only match `.profile-link` / `[data-uia="profile-link"]`,
   so the bar says "Open" instead of "Choose" and the initial ring landed on the Netflix logo.

4. **Minor - the controller never "sleeps".** After 11 s without input `nfc-active` stays set and the bar and
   ring stay at opacity 1. Only a real `mousemove` removes the class; nothing resets `controllerActive`.

5. **Minor - turning TV mode back on shows no lift/info panel until the next move.** `applyTvMode()` (~493)
   only clears state; it never calls `updateTvFocus(focused)` when enabling.

6. **Minor - B with the Genres dropdown open leaves the page instead of closing the dropdown.** On
   Movies > Genres > A > B, `goBack` runs `history.back()` to `/browse`; `closeModal` doesn't treat the genre
   menu as a closable popup. After picking a genre the ring also sometimes lands on the top-nav "Home" link
   rather than content.

7. **Minor - the first B after a mouse hover is swallowed.** Hovering a card shows Netflix's mini-modal; the
   next controller press hides it with CSS but `getModal()` still reports `modal-motion-container-MINI_MODAL`,
   so B "closes" it instead of acting.

8. **Minor - the ring stays drawn while the OSK is open**, often on the old card which the expanded search
   box has pushed off-screen (x = -208). The URL watcher can also move it behind the OSK while typing.

9. **Cosmetic** - OSK Up/Down isn't reversible (proportional column mapping: Done > Down > "9", not "0").
   "Scroll row" shows on the My List grid. Fullscreen fallback toast says "Firefox" (fine in Firefox).
   On the DRM error page the bar still offers the full player set with no reachable links; B exits fine.
   The ring stays visible in mouse mode after `nfc-active` is removed (bar fades, ring doesn't).

## Reported by agents, needs confirmation in Firefox (timing-sensitive, seen only in background tabs)

- **Row-edge paging can leave the ring on an off-screen card or lose focus** (agent saw ring at x = -457 /
  -1215, then `focused` detached). Suspected cause: `pageRow()` (~583-609) detects "nothing slid" by comparing
  the first card's left edge, but the Hawkins carousel recycles DOM so the first card returns to the same left
  with new content. In the visible tab, paging at both edges plus LB/RB landed in view every time, including
  13 fast presses, so this may be a hidden-tab artefact. Worth a real-pad check on long rows.
- **Y (jump to top) and LT/RT (page up/down) pick the new focus after a fixed 450 ms** (`pageScroll` ~638,
  `case "y"` ~1356) before smooth scrolling finishes, leaving the ring off-screen. Consider waiting for
  `scrollend` or for scrollY to settle.
- **Right-stick scrolling leaves focus behind**; the next D-pad press snaps the page back to the old card.
  `onStick` (~1368) could re-pick a visible card on release.
- **Episodes "show more" (`section-expand`) unreachable going Down** from the last episode: it overlaps the
  episode box by ~28 px so `findBest` (~450) rejects it. The More-like-this expand button *was* reachable in
  the visible tab.
- Dialog focus on Play took ~1.65 s once (target ~0.5 s); Down from the button row skips the season picker
  (only reachable with Up from episode 1); after exiting the player from an episode, focus returns to Play
  rather than the episode and the season resets. One unreproduced case where B closed the dialog but the
  ring did not return to the card.
- Once, Start after a no-results search left the ring on a footer link (URL watcher ran `restoreFocus` ->
  `pickInitial` while the OSK was open).

## What worked

- Wake: ring on billboard Play, bar "Navigate Play Search Help". Up reaches the top nav, Down returns.
- Rows: Up/Down across 7-12 rows always on a card, fixed row height in TV mode, ring in view, no headers or
  wrong rows. Left/Right card by card; LB/RB and edge paging land on visible cards (visible tab). Holding Right
  auto-repeats without skipping rows. Footer links reachable at the bottom and Up comes back.
- TV mode: lift + info panel (row name + title) on cards, cleared on billboard/nav; off = plain ring.
- Controls bar: context labels on home, cards, Play, dialog (Play / Close / My List), OSK, player; "Back"
  hidden on Home; glyph styles re-render live; `showHints` hides it immediately; repeat settings apply live.
- Help overlay: Start opens, D-pad doesn't move underlying focus, B closes.
- Title dialog: A opens with ring on Play; Left/Right stays on the button row and skips tag/cast links; Y
  toggles My List with the bar label flipping; season dropdown open/move/pick/close works; A on an episode
  starts playback with "Loading..." toast; B closes and returns to the same card (3/4 tries).
- Search: X opens the OSK (SPA, no reload); typing/space/delete update the query and results; wrap-around and
  repeat on the keyboard; result grid navigation; A opens a result's dialog and B returns to it; B from
  results returns to the pre-search card with scroll position; X in search reopens the OSK with the query kept;
  Y on a result jumps to top; no-results search produces no errors.
- Secondary pages: Shows, Movies, New & Popular, My Netflix, Browse by Languages all SPA-navigate; B returns to
  `/browse` on the nav link you left from; genre dropdown navigable; My List grid navigable; View = Home;
  double-B never goes back two steps.
- Player (entry/exit only): A on Play goes to `/watch` with the player bar; Right/Y/RT/LT/R3/L3 show their
  fallback toasts when no player API exists; RT/LT do not repeat-fire while D-pad does; B exits back to the
  exact launch point (billboard Play, or the dialog's Play with the dialog still open). No console errors.

- Fullscreen (synthetic input is not a user gesture).
- Movie dialogs ("More like this" from a movie), X-from-dialog-to-search, OSK with the analog stick, "Scroll row"
  hidden on a non-scrollable row (none existed), rows beyond 12.
